Реализация процесса обучения модели на примере классической задачи распознавания рукописных цифр с точностью как минимум 92% на тестовой выборке. Весь датасет с необходимым набором данных содержится в директории MNIST.

В результате успешного обучения модели с заданной точностью, которое выполнено в основном файле с названием hw_mnist_classification, формируется соответствующая json-структура в файле submission_dict_mnist, полученная на основе данных из прилагаемого словаря hw_mnist_data_dict.
